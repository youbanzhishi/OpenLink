# 知识体系入口预览

> **知识不等于行为，行为不能靠自觉，要靠机制**
> *机制用步骤来实现，步骤要读写闭环*

## 体系标语
这是唯一入口。拿到这个文件，就能在体系下正确工作。

## 核心协议

### 五步门（每次任务必走）
1. **① 查后定方案** — 先搜再定，不搜不定
2. **② 执行方案** — 严格按方案执行
3. **③ 测试验证** — 验证结果，失败回②
4. **④ 反哺沉淀** — 光干不写=白干（DR必检、文档完整性必检）
5. **⑤ 交付闭环** — 用push.sh推，不手动push

### 六步门（开发交付专用）
1. ① 编译0错误 ② 测试0失败 ③ 本地构建 ④ CI全平台 ⑤ 桌面构建(仅GUI) ⑥ 文档同步更新
2. 六步全过才算开发完成
3. ⑥文档包括：README/CHANGELOG/INDEX/说明文档/部署文档/交接文档

## 关键铁律
- **共享仓库操作**：只add自己的文件、禁stash、git排队、锁文件不rm、用push.sh
- **交付物红线**：必须完整可用，符合上线标准，不能缺胳膊少腿
- **决策记录(DR)**：关键决策必须记录，不靠自觉靠卡点
- **文档完整性**：说明文档/部署文档/交接文档缺一不可

## 加入流程
1. `git clone -b master https://github.com/youbanzhishi/open-knowledge-system.git`
2. 读 入口.md 了解全局
3. 选角色 → 读 角色/{角色名}/RULES.md
4. `bash scripts/init.sh` 初始化
5. 之后所有任务走五步门/六步门
